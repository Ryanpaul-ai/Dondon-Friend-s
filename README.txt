SOLE.STYLE - Updated Shoe Store Demo

This version includes the eight generated product photos and a matching dark storefront design.

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted sole-style-updated folder in VS Code.
3. Open index.html.
4. Optional: use the Live Server extension and choose Open with Live Server.

FILES
- index.html: Website structure.
- css/style.css: Responsive storefront styling.
- js/script.js: Product list, search, category filters, sorting, and cart behavior.
- assets/hero-shoe.jpg: Hero section image.
- assets/shoes/: Eight individual shoe product images.

NOTE
This is a front-end demo. Checkout is a placeholder and does not process real payments or orders. Prices and product names are sample content.
